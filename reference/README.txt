Symbol list of The Sims 2 (GameCube, G4ZE69), from https://github.com/natebag/Sims2DECOMP
(config/G4ZE69/symbols.txt). That game shares this engine and shipped with a symbol map,
so its function names and their order are the best naming reference available.
Addresses in this file are for The Sims 2, not for Bustin' Out.
