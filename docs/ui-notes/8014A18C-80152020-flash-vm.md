# 0x8014A18C-0x80152020: the ActionScript VM (not the display list)

KEY FINDING: this part of the "2D UI library" is a Flash (SWF / ActionScript 1) player runtime. The UI is
Flash movies. The display objects are movie clips; this slice holds the bytecode interpreter, value types,
String natives, a PRNG. There is no draw/layout code here. Position/scale/alpha live behind the
property get/set path (see "Properties").

src/ui/Unk8014A18C.cpp (+ _c.c) and src/ui/Unk8014FD8C.cpp. Unit 2 ends at 0x80152020; 0x80152020-0x80153C2C
is the Metrowerks GBA SDK, the EOR engine unit starts 0x80153C2C (static init at 0x80154380).
