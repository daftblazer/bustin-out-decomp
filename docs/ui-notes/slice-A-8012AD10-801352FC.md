# Apt runtime, slice A: 0x8012AD10-0x801352FC

The library is EA's **Apt** (Flash/ActionScript player), the same code as The Sims 2's `Apt*` classes
(`reference/sims2_symbols.txt`, `AptValue`, `AptCIH`, `AptNativeHash`, `AptArray`, `AptDisplayList`).
Compiled at -O0 with ProDG, C++ (member functions keep `this` in r29-r31, `__builtin_new`, in-charge dtors).
Sims 2 sizes do not align with these (different version), so names are by structure only.

## Globals
- `0x8033D1E0` (.bss, 0x7C): host callbacks. +0 alloc(size), +4 free(p), +8 free(p,size) (default `fn_8012AD10`, which calls +4).
  +0x18, +0x1C: debug text sinks (used by fn_8012B120).
- `0x8037D0F4` (r13-0x62EC): main Apt state, 0x3F3C bytes (ctor 0x80138A50). **+0x3A18 = root display list** (embedded; first word
  = root char instance); +0x3E24 cleared by fn_8012BB44.
- `0x8037D0F8`: 0x6708-byte object (ctor 0x801430FC), `0x8037D0FC`: 0x448C-byte object (ctor 0x80144320).
- `0x8037D100` initialised flag, `0x8037D104` input-gremlin (random input) enable, `0x8037D0F0` accumulated ticks,
  `0x8037D110` shared "undefined" value, `0x8037D108` deleted-hash-slot marker.
- `0x8033D25C` (0x14): saved-input record/playback state (+0 active, +4 cursor, +8 end, +0x10 frame).
- `0x802D67B4`: table of 0x1D per-type release handlers, indexed by AptValue type. Types 0xC-0x13 (character instances) all use 0x80132924.

## Entry points (API, Sims 2 names in parentheses)
- fn_8012AD64 = AptInitialize: fills defaults, creates the three state objects above.
- fn_8012AE10 = AptShutdown. fn_8012AE70 = get/create root animation at level N (list at state+0x3A18; creates a 0x60-byte
  char instance, type 0x13, via fn_8012C21C, plus a 0x10-byte holder at +0x4C).
- fn_8012AF98 = AptGetAnimationSize(int* w, int* h): reads root->data(+0x4C)->+8 -> **+0x1C width, +0x20 height** (the Flash stage size, a
  place where 640x480 comes from the SWF itself).
- fn_8012B1BC = _AptInternalUpdate(ticks): frame time at animation data +0x24; accumulates ticks in +0x20 of char data; when >= frame time runs the
  update chain (0x80138D30, 0x8013D538, 0x80139110, 0x80144974, 0x801438E4, 0x80131E04).
- fn_8012B318 (0x6E0) = input gremlins / saved-input playback (random mouse and button events, debug only).
- fn_8012B9F8 = AptRender: `fn_80139AA4(state); fn_8013D28C(&state->rootList, lbl_8037D124, 0)`.
- fn_8012BA5C = AptSetMousePosition(x, y) -> 0x801393C8 (skipped when playback is active). fn_8012BACC = AptAddToInputQueue(a,b,c) -> 0x8013934C.

## Character instance (display object) layout, ctor fn_8012C21C(this, type, data, parent)
- +0x00 AptValue header; +0x08 = 0
- +0x0C..0x20: 2x3 matrix, initialised 1,0,0,1,0,0 (a,b,c,d then translation pair; floats)
- +0x24..0x30: colour multiply rgba = 1.0; +0x34..0x40: colour add rgba = 0.0
- +0x44 = 0; +0x48 parent (AddRef'd); +0x4C data/character definition (fn_8012C350 returns it); +0x58, +0x5C = 0.

## AptValue header (word at +0)
bits 0-14 type (fn_8012C7C8), bit 15 "defined" (fn_8012C998; fn_8012C8A4 = !defined), bits 16-31 reference count (fn_8012C95C get, fn_8012C9D0 set).
`fn_8012C800` AddRef (skips the shared undefined value and types 0x0B, 0x17, 0x18). Type test helpers: 0x8012C188 isCIH (types 0xC-0x13),
0x8012C37C type 0x12, 0x8012CAA8/CB18/CB88 types 0x0B/0x18/0x17.

## Containers
- AptNativeHash: {+0 bits, +4 items}; items are {key AptString, value}, 1<<bits slots, linear probe 16 then double (fn_8012CEF0, HashSet).
  Key characters at AptString+4 (fn_8012D9C4). Hash = h*33+c (fn_8012CC2C). Lookup by C string fn_8012D6E0, unset fn_8012D4CC, iteration D878/D934.
- AptArray (type 0x16, ctor fn_8012D9F0): +0xC data, +0x10 capacity, +0x14 length; get(i) fn_8012E088 (out of range gives the undefined value),
  reserve fn_8012DE18, toString/join fn_8012E11C. Native method names registered in fn_8012E250 (length concat join pop push shift unshift reverse splice).
- Button events registered in fn_80130044 (onRelease, onPress, onReleaseOutside, onRollOver, onRollOut, onDragOver, onDragOut); focus navigation
  (_up/_down/_left/_right) in fn_80131630.

## Coordinates
No 640/480 constants were seen in this slice; the stage size comes from the animation data (+0x1C/+0x20, fn_8012AF98) and the mouse position is
passed straight through fn_8012BA5C. Per-frame tick counter: 0x8037D0F0.

## Source notes
Built with `tools/tu0.sh src/ui/X.cpp -v` (-O0). Functions are members with `asm("fn_XXXXXXXX")` labels (constructors work too; destructors do not:
`~AptNativeHash` is renamed `_._13AptNativeHash`). After a constructor or a function returning a local, the compiler emits only one
branch to the epilogue per return for the rest of the file; `APT_RETURN` / `do { } while (0)` restores the original's three.
