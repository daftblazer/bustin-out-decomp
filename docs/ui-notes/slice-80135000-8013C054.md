# Apt (Flash/ActionScript) VM: 0x801352FC-0x8013C054

Unit `src/ui/Unk801352FC.c` (-O0, compiled as C; 68 functions match). The range is NOT display objects:
it is the ActionScript VM context, its message queue, setInterval timers, and Math natives.
Display-object drawing lives in the neighbouring slices (0x8013D1F8 etc.).

## Object model
- Every VM object starts with a word whose low 15 bits (`clrlwi 17`) are the type index
  (`fn_8012C7C8`). `lbl_802D67B4[type]` (29 entries) is the release function. Type 0x13 = callable/clip-like
  (`fn_80139D88`). `fn_8012C800` = add reference.
- `lbl_8033D1E0` is a platform table of function pointers: +0x00 alloc, +0x08 free(p,size),
  +0x18 trace hook(&{tag,word}, 8), +0x40 release for a handle.
- `lbl_8033D2A8` is the machine (`AptMachine`): +0x000 an `AptList128` object stack, +0x61C current id.
  `lbl_8033D838` is another `AptList` stack. `lbl_8037BEB0..BF6C` (.sdata) are cached global objects
  (released by the shutdown destructors 80135EAC/80136410/801352FC).

## Context object `AptCtx` (0x3F3C bytes), constructor fn_80138A50, destructor fn_80138B28
- 0x0000-0x13FF message ring: 256 slots of 0x14 bytes `{type, id, a, b, c}`
  (type 0 = call b with id; type 1 = two objects + number). next/prev slot: fn_80139F24 / fn_80139F70.
- 0x1400 ring read ptr, 0x1404 write ptr. Enqueue: 801396A4 (tail), 80139748/801397EC (head);
  run: 80139110; flush: 8013954C; remove by object: 801398B0.
- 0x1408 root object array [256], 0x1808 root count (released by fn_80138F68).
- 0x180C object list {count, items[256]} (ends 0x1C10); 0x1C10 call-frame count, 0x1C14 frames[256] of
  0x1C bytes {obj, 6 words} (push 80139B58, remove 80139C00, clear 80139AA4).
- 0x3814 object list {count, items[128]}; 0x3A18/0x3A1C two small objects.
- 0x3A20 setInterval timers: 64 x 0x10 bytes `{used, clip obj, float interval, float remaining}`;
  0x3E20 timer count. fn_80138D30(ctx, dt) subtracts dt (INT, units of the caller's clock, converted to
  float) from `remaining`; when it drops below 0 it runs the callback (8014A254) and adds `interval`.
  clearInterval = fn_8013942C. No screen-space data here.
- 0x3E24 event word count, 0x3E28 event words[64] (fn_801392B0 push; encoders 8013934C / 801393C8:
  `clip:15 <<17 | ...`). 0x3F28..0x3F38 misc (0x3F38 = locked/modal root, fn_80139D04 walks the parent
  chain at +0x48).

## Notes for the recomp
- Nothing here depends on 640x480; the timer step is the only per-frame quantity (dt passed in).
- Language: C-style, but `new T(...)` sites (ctor result stored straight from r3) are C++; those few
  functions (80139E1C, 8013A4E0, 8013934C, 8013A2AC) are marked NON_MATCHING.
